# GoCommerce

A microservices-based e-commerce backend built with Go.

## Overview

GoCommerce is an educational project focused on building a scalable e-commerce backend using Golang and Microservices Architecture.

## Tech Stack

- Go
- Gin
- PostgreSQL
- GORM
- Docker
- RabbitMQ
- Redis

## Architecture

The project is designed as a monorepo with independently managed Go services.

### Services

- Product Service
- User Service
- Order Service
- Payment Service
- Notification Service
- API Gateway

## Project Structure

```text
gocommerce/
└── services/
    └── product-service/
```

## Project Status

Currently under development.

## Goals

- Learn Microservices Architecture
- Build RESTful APIs using Go
- Work with PostgreSQL and GORM
- Implement inter-service communication
- Containerize services using Docker
- Prepare a production-oriented backend project
